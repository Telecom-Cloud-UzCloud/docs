# ISO import qilish

## ISO obraz

**ISO obraz** — fayl tizimining aniq nusxasini oʻz ichiga olgan disk obrazi fayli. UzCloud’da virtual mashinaga nostandart operatsion tizim yoki vositalarni oʻrnatish uchun oʻz ISO obrazingizni import qilish mumkin.

---

### ISO obrazni import qilish

- Chap menyuda **ISO** ni bosing. Sahifada ISO obrazlaringiz koʻrsatiladi.
- **Create ISO** tugmasini bosing. **Create ISO** sahifasi ochiladi.

![ISO](../../images/iso-1.png)

- ISO obraz tegishli boʻladigan loyihani tanlang.

![Loyihani tanlash](../../images/iso-2.png)

- ISO obraz saqlanadigan joylashuvni tanlang.

![Joylashuvni tanlash](../../images/iso-3.png)

### ISO parametrlari

- **Select OS** — ISO obrazning operatsion tizimi.
- **Select Image** — obraz turi.
- **URL** — import qilinadigan ISO faylga havola.
- **Name** va **Description** — ISO obraz nomi va qisqacha tavsifi.

Qoʻshimcha parametrlar:

- **Password Enabled** — obraz parol oʻrnatishni qoʻllab-quvvatlaydi.
- **Is Bootable** — VM’ni ushbu ISO’dan yuklash mumkin (masalan, OT oʻrnatish uchun).
- **Is Extractable** — import qilingandan soʻng ISO obrazni yuklab olish mumkin.

**Price Summary** ni tekshiring (ISO’ni saqlash narxi har bir GB uchun soatiga hisoblanadi) va **Review & Create ISO** tugmasini bosing.

![ISO parametrlari](../../images/iso-4.png)

> [!TIP]
> ISO obrazni virtual mashinaga ulash uchun VM sahifasida **Attach ISO To This Virtual Machine** ni bosing.

### Xulosa

ISO obrazlar virtual mashinalarga istalgan operatsion tizim yoki vositalarni oʻrnatish imkonini beradi. Yordam kerak boʻlsa, UzCloud hujjatlarini oʻrganing yoki qoʻllab-quvvatlash xizmatiga murojaat qiling.
