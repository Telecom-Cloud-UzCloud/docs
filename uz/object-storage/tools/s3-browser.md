# S3 Browser

**S3 Browser** — Windows uchun grafik S3 mijozi. Bepul versiyasi shaxsiy foydalanish uchun mavjud.

## Oʻrnatish

S3 Browser’ni [s3browser.com](https://s3browser.com/download.aspx) dan yuklab oling va oʻrnating.

## Hisob qoʻshish

1. **Accounts → Add new account** ni oching.
2. **Display name**: istalgan nom, masalan `UzCloud`.
3. **Account type**: **S3 Compatible Storage**.
4. **REST Endpoint**: `s3.uzcstorage.uz`.
5. **Access Key ID** va **Secret Access Key** ni kiriting va **Use secure transfer (SSL/TLS)** ni belgilang.
6. **Advanced S3-compatible storage settings** ni bosing va **Addressing model** uchun **Path style** ni tanlang.
7. **Add new account** ni bosing.

Bucketlar roʻyxati ochiladi. Fayllarni yuklash uchun ularni oynaga sudrab tashlang; yuklab olish, oʻchirish va havolalar yaratish kontekst menyusida mavjud.
