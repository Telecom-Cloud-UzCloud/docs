# Change Startup Script

## Change Startup Script

Startup scripts are executed automatically when the virtual machine starts. Use them to install software, apply updates, or configure applications.

---

- On the **VM Settings** tab, select **Change Startup Script**.
- Enter the script and click **Change**.

![Change Startup Script](../../../images/vm-startup-script.png)

---

### Conclusion

A well-written startup script ensures consistent VM configuration. Check the script syntax before saving it to avoid errors at startup.
