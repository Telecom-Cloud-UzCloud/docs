# Monitoring Resources

## Resource Monitoring for UzCloud

UzCloud lets you track the resource usage of each instance with charts. Use them to assess performance, find bottlenecks, and plan resources.

- On the **Instances** page, click the instance name to open the **Virtual Machine Overview** page.
- Go to the **Usage Graphics** tab.
- For each chart, select the period in the drop-down list in its top-right corner: **Last 24 Hours**, **Last 12 Hours**, **Last 6 Hours** or **Last 1 Hour**.

### CPU Usage

The **CPU Usage** chart shows processor utilization over the selected period. Use it to detect load peaks and to decide whether the instance needs a larger plan.

![CPU Usage](../../images/vm-usage-cpu.png)

### Disk Read Write

The **Disk Read Write** chart shows the amount of data read from and written to the disk over time. It helps you analyze disk performance and find storage bottlenecks.

![Disk Read Write](../../images/vm-usage-disk.png)

### Memory Usage

The **Memory Usage** chart shows used memory compared with allocated memory. Use it to monitor memory consumption and spot possible memory leaks.

![Memory Usage](../../images/vm-usage-memory.png)

### Network Traffic

The **Network Traffic** chart shows the amount of data transferred over the network. Use it to monitor network load, identify traffic patterns and troubleshoot network issues.

![Network Traffic](../../images/vm-usage-network.png)

### Disk IO Read Write

The **Disk IO Read Write** chart shows the number of disk input/output operations: reads, writes, and the total.

![Disk IO Read Write](../../images/vm-usage-disk-io.png)

### Conclusion

By using these charts, you can monitor the performance of your instances in real time, address potential issues before they affect operations, and optimize resource usage. For further assistance, refer to the UzCloud documentation or reach out to support.
