# Manage Veeam Backup

## Veeam Backup Account Overview for UzCloud

The **Veeam Account Overview** page provides detailed information and management options for your Veeam backup configuration. It shows account details, resource quotas, and options for performing administrative tasks.

---

### Action Buttons

- Action Buttons provide shortcuts for essential Veeam Backup management tasks.
- To view Action buttons, click on the backup created, which will redirect you to the **Veeam Backup** page.
- **Refresh:** Reloads the latest account data, including current status and resource metrics.
- **Console Access:** Opens a console interface to interact with the Veeam Backup server directly.
- **Delete:** Permanently deletes the Veeam account and all associated resources.

### Veeam Backup Overview

- **Project Name:** The name of the user-defined project under which the Veeam account was created.
- **Created At:** Timestamp showing when the Veeam account was created.
- **Username:** The default username for accessing the Veeam Backup server.
- **Status:** The current state of the Veeam account (e.g., Running, Stopped).
- **Location:** The geographic location of the data center.

---

### Conclusion

The **Veeam Backup Account Overview** centralizes the visibility of backup quotas, account activity, and billing cycles. It simplifies management and provides clear insight into your backup configuration and consumption across Veeam infrastructure.
