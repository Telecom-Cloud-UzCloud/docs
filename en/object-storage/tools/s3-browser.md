# S3 Browser

**S3 Browser** is a graphical S3 client for Windows. The free version is available for personal use.

## Installation

Download S3 Browser from [s3browser.com](https://s3browser.com/download.aspx) and install it.

## Add an Account

1. Open **Accounts → Add new account**.
2. **Display name**: any name, for example `UzCloud`.
3. **Account type**: **S3 Compatible Storage**.
4. **REST Endpoint**: `s3.uzcstorage.uz`.
5. Enter the **Access Key ID** and **Secret Access Key**, and select **Use secure transfer (SSL/TLS)**.
6. Click **Advanced S3-compatible storage settings** and set **Addressing model** to **Path style**.
7. Click **Add new account**.

The list of buckets opens. Drag files into the window to upload them; use the context menu to download, delete or generate a web URL.
