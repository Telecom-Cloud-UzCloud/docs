# Выписка по аккаунту

## Выписка по аккаунту

Вкладка **Account Statement** содержит финансовый документ с полной сводкой всех транзакций, платежей и использования ресурсов по аккаунту за определенный период. Выписка помогает отслеживать расходы, проверять начисления и обеспечивает прозрачность биллинга.

- **Invoices** — счета за использованные услуги.
- **Usage Details** — детализация потребления ресурсов.
- **Free Trials** — пробные сервисы, которые могут перейти в платные подписки.
