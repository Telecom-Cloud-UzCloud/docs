# Управление Veeam Backup

## Обзор аккаунта Veeam Backup в UzCloud

Страница **Veeam Account Overview** содержит подробную информацию о настройке резервного копирования Veeam и инструменты управления: сведения об аккаунте, квоты ресурсов и административные действия.

---

### Кнопки действий

- Кнопки действий — быстрый доступ к основным операциям с Veeam Backup.
- Чтобы увидеть кнопки действий, нажмите на созданный аккаунт — откроется страница **Veeam Backup**.
- **Refresh** — загружает актуальные данные аккаунта, включая статус и метрики ресурсов.
- **Console Access** — открывает консоль для прямой работы с сервером Veeam Backup.
- **Delete** — безвозвратно удаляет аккаунт Veeam и все связанные ресурсы.

### Обзор Veeam Backup

- **Project Name** — имя проекта, в котором создан аккаунт Veeam.
- **Created At** — дата и время создания аккаунта Veeam.
- **Username** — имя пользователя по умолчанию для доступа к серверу Veeam Backup.
- **Status** — текущее состояние аккаунта Veeam (например, Running, Stopped).
- **Location** — географическое расположение дата-центра.

---

### Заключение

Страница **Veeam Backup Account Overview** собирает в одном месте квоты резервного копирования, активность аккаунта и периоды оплаты. Она упрощает управление и дает наглядное представление о настройках и потреблении ресурсов инфраструктуры Veeam.
