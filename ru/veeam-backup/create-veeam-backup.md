# Veeam Backup

## Veeam Backup

**Veeam Backup** — комплексное решение для резервного копирования и восстановления, которое защищает виртуальные, физические и облачные рабочие нагрузки. В UzCloud Veeam Backup обеспечивает доступность данных, аварийное восстановление и удобное управление резервными копиями облачных ресурсов. В этом руководстве пошагово описано, как создать аккаунт Veeam Backup и управлять им.

---

### Создание Veeam Backup

- В меню слева откройте вкладку **Veeam Backup**.
- Откроется страница **Veeam Backup**.

![Вкладка Veeam Backup](../../images/veeam-1.png)

- Чтобы создать Veeam Backup, нажмите **Create Veeam Account** или **Create New** в правой части страницы.

### Выбор проекта

- Привяжите сервер Veeam Backup к одному из ваших проектов, чтобы удобно организовывать ресурсы и управлять ими.

![Выбор проекта](../../images/veeam-2.png)

### Выбор расположения

- Выберите дата-центр, в котором будет физически размещен сервер Veeam Backup.
- Выберите одно из доступных расположений.

![Выбор расположения](../../images/veeam-3.png)

### Выбор плана

- Выберите план или создайте собственный в соответствии с вашими требованиями.

![Выбор плана](../../images/veeam-4.png)

- **Repository Quota** — ограничивает общий объем хранилища для резервных копий.
- **VM's Quota** — ограничивает количество виртуальных машин, которые можно резервировать.
- **Workstations Quota** — максимальное количество рабочих станций для резервного копирования.
- **Servers Quota** — ограничивает количество физических серверов для резервного копирования.
- **Concurrent Task** — количество одновременных задач резервного копирования или восстановления.

### Имя Veeam Backup

- Укажите уникальное **Name** и понятное **Description** для аккаунта Veeam, чтобы легко находить его в панели управления.

![Имя Veeam Backup](../../images/veeam-5.png)

### Проверка и развертывание

- Выберите нужный **Billing Cycle**. Для Veeam Backup поддерживаются периоды: почасовой, ежемесячный, ежеквартальный, раз в полгода, ежегодный, раз в два года и раз в три года.
- Поддерживаемые правила биллинга: Date to Date, Fixed Calendar Month, Unfixed Calendar Month, Fixed Prorata и Unfixed Prorata.
- Доступны разные пакеты в зависимости от объема SSD и расположения дата-центра — это дает гибкость при построении стратегии резервного копирования для разных регионов и уровней хранения.
- Проверьте все параметры и итоговую стоимость. Нажмите **Review And Create Veeam Account**, чтобы создать аккаунт Veeam.

![Проверка и развертывание](../../images/veeam-6.png)

### Заключение

Следуя этому руководству, вы легко создадите аккаунт Veeam Backup в UzCloud и сможете управлять им. Veeam Backup обеспечивает защиту данных, аварийное восстановление и удобное управление резервными копиями облачных ресурсов.
