# Инструменты для объектного хранилища

Объектное хранилище UzCloud совместимо с Amazon S3 API. С ним можно работать из консоли и из любого S3-клиента: утилит командной строки, файловых менеджеров и SDK для языков программирования.

## Параметры подключения

Любому инструменту нужны одни и те же параметры:

| Параметр | Значение |
|---|---|
| Адрес (endpoint) | `https://s3.uzcstorage.uz` |
| Регион | `default` |
| Стиль адресации | path-style: `https://s3.uzcstorage.uz/<бакет>/<объект>` |
| Access Key / Secret Key | ключи вашего объектного хранилища |

### Где взять ключи

1. Откройте **Object Storage** в консоли и нажмите на имя хранилища.
2. Нажмите **Credentials**. Access Key показан в списке **Access Keys**.
3. Secret Key показывается только в течение 5 минут после нажатия **Create Key**. Скопируйте его сразу и сохраните в менеджере паролей. Если секрет утерян, создайте новый ключ и отзовите старый.

![Учетные данные S3](../../../images/ob-17.png)

См. **[Управление объектным хранилищем](../../object-storage/manage-object-storage.md#просмотр-учетных-данных)**.

> [!IMPORTANT]
> Указывайте имя бакета точно так, как оно показано в консоли, например `demo-store-001045`.

## Выбор инструмента

| Инструмент | Тип | Подходит для |
|---|---|---|
| [AWS CLI](aws-cli.md) | Командная строка | Скрипты, автоматизация, все возможности S3 |
| [s3cmd](s3cmd.md) | Командная строка | Простая загрузка и синхронизация на Linux-серверах |
| [rclone](rclone.md) | Командная строка | Синхронизация, бэкапы, перенос между облаками |
| [s3fs](s3fs.md) | Файловая система | Подключение бакета как папки в Linux |
| [Cyberduck](cyberduck.md) | Графический | Работа с файлами в macOS и Windows |
| [S3 Browser](s3-browser.md) | Графический | Работа с файлами в Windows |

Для приложений используйте [SDK](../sdk/overview.md) для своего языка программирования.
