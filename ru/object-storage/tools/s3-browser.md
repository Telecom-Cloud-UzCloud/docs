# S3 Browser

**S3 Browser** — графический S3-клиент для Windows. Бесплатная версия доступна для личного использования.

## Установка

Скачайте S3 Browser с [s3browser.com](https://s3browser.com/download.aspx) и установите.

## Добавление аккаунта

1. Откройте **Accounts → Add new account**.
2. **Display name**: любое имя, например `UzCloud`.
3. **Account type**: **S3 Compatible Storage**.
4. **REST Endpoint**: `s3.uzcstorage.uz`.
5. Введите **Access Key ID** и **Secret Access Key** и отметьте **Use secure transfer (SSL/TLS)**.
6. Нажмите **Advanced S3-compatible storage settings** и выберите **Addressing model** — **Path style**.
7. Нажмите **Add new account**.

Откроется список бакетов. Перетащите файлы в окно, чтобы загрузить их; скачивание, удаление и создание ссылок доступны в контекстном меню.
