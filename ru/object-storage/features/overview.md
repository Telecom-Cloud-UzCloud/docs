# Поддерживаемые возможности

Объектное хранилище UzCloud построено на Ceph и поддерживает основные возможности Amazon S3 API. В таблице перечислены возможности и способы работы с ними.

| Возможность | Для чего | Консоль | S3 API |
|---|---|---|---|
| [Версионирование](versioning.md) | Хранение предыдущих версий объектов | ✓ | ✓ |
| [Object Lock](object-lock.md) | Защита объектов от удаления (WORM) | ✓ | ✓ |
| [Жизненный цикл](lifecycle.md) | Автоматическое удаление старых объектов | — | ✓ |
| [CORS](cors.md) | Доступ с веб-страниц других доменов | — | ✓ |
| [Bucket Policy](bucket-policy.md) | Правила доступа к бакету | ✓ | ✓ |
| [Заголовки объектов](object-headers.md) | Content-Type, Cache-Control, метаданные | — | ✓ |
| [Мультипарт-загрузка](multipart-upload.md) | Загрузка больших файлов частями | — | ✓ |
| [Presigned URL](presigned-url.md) | Временные ссылки на закрытые объекты | — | ✓ |
| [Проксирование через Nginx](nginx-proxy.md) | Собственный домен и кеширование | — | — |
| [Статический сайт](static-website.md) | Размещение статического сайта в бакете | — | ✓ |

Для возможностей, которых нет в консоли, используйте **[инструменты](../tools/overview.md)** или **[SDK](../sdk/overview.md)**.
