# Создание объектного хранилища

## Объектное хранилище S3

**Объектное хранилище** UzCloud — это S3-совместимое хранилище на базе **Ceph**. Оно подходит для файлов, резервных копий, медиаконтента и других неструктурированных данных и работает с любыми S3-клиентами и SDK. Ниже описано, как создать объектное хранилище в консоли UzCloud.

---

### Откройте страницу Object Storage

- В левом меню в разделе **STORAGE** нажмите **Object Storage**. На странице перечислены ваши хранилища: проект, расположение, размер, стоимость за все время, использование и дата создания.
- Нажмите **+ Create New** в правом верхнем углу. Откроется страница **Create Object Storage**.

![Страница Object Storage](../../images/ob-1.png)

### Выберите проект

- Привяжите хранилище к одному из своих проектов, чтобы упорядочить ресурсы.

![Выбор проекта](../../images/ob-2.png)

### Выберите расположение

- Выберите расположение, в котором будет размещено хранилище.

![Выбор расположения](../../images/ob-3.png)

### Укажите размер и имя

- В блоке **Select Object Storage size** укажите размер хранилища в ГБ. Цены за месяц и за час рассчитываются автоматически.
- Укажите имя хранилища в поле **Name**.

![Размер и имя](../../images/ob-4.png)

### Создайте хранилище

- Внизу страницы выберите **Billing Cycle** (цикл оплаты): **Monthly** (ежемесячно) или **Yearly** (ежегодно). В **Price Summary** показана стоимость выбранной конфигурации.
- Проверьте конфигурацию и нажмите **Review & Create**.

![Создание хранилища](../../images/ob-7.png)

### Заключение

Следуя этому руководству, вы создадите S3-совместимое объектное хранилище в UzCloud. Далее создайте бакеты и получите ключи доступа — см. **[Управление объектным хранилищем](manage-object-storage.md)**. Если нужна помощь, изучите документацию UzCloud или обратитесь в поддержку.
