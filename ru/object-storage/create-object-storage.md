# Создание объектного хранилища

## Объектное хранилище Ceph

**Ceph** — надежное и масштабируемое объектное хранилище для хранения данных и управления ими. **UzCloud** предоставляет встроенную интеграцию с Ceph, позволяя удобно создавать объектные хранилища и управлять ими. Ниже пошагово описано, как настроить **объектное хранилище Ceph** в панели управления UzCloud.

---

### Создание объектного хранилища Ceph

- В меню слева откройте вкладку **Object Storage**.
- Чтобы создать объектное хранилище, нажмите **Create Object Storage** или **Create New** в правой части страницы. Откроется меню создания.

![Создание объектного хранилища](../../images/ob-1.png)

### Привязка к проекту

- Привяжите объектное хранилище к одному из ваших проектов, чтобы удобно организовывать ресурсы и управлять ими.

![Привязка к проекту](../../images/ob-2.png)

### Выбор расположения

- Выберите дата-центр, в котором будет физически размещено хранилище.
- Выберите одно из доступных расположений.

![Выбор расположения](../../images/ob-3.png)

### Размер объектного хранилища

- Выберите план в соответствии с требованиями к типу и размеру хранилища. При необходимости можно создать собственный план.
- Стоимость будет зависеть от выбранных ресурсов.

![Размер объектного хранилища](../../images/ob-4.png)

### Имя хранилища

- Укажите уникальное **Object Name**, чтобы легко находить хранилище в панели управления.

![Имя хранилища](../../images/create-object-storage-inline-649a275b.png)

### Создание хранилища

- Выберите нужный **Billing Cycle**. Для Ceph Object поддерживаются периоды: почасовой, ежемесячный, ежеквартальный, раз в полгода, ежегодный, раз в два года и раз в три года.
- Поддерживаемые правила биллинга: Date to Date, Fixed Calendar Month, Unfixed Calendar Month, Fixed Prorata и Unfixed Prorata.
- Доступно несколько вариантов конфигурации. Сервис предоставляет гибкое масштабируемое объектное хранилище для различных cloud-native сценариев.
- Проверьте все параметры и итоговую стоимость. Нажмите **Review and Create**, чтобы создать хранилище.

![Создание хранилища](../../images/ob-7.png)

### Заключение

Следуя этому руководству, вы легко настроите **объектное хранилище Ceph** в UzCloud и сможете управлять им. Это масштабируемое и надежное решение для эффективного хранения данных. Если нужна помощь, изучите документацию UzCloud или обратитесь в поддержку.
