# Nextcloud с S3

**Nextcloud** — платформа для хранения файлов и совместной работы, которую можно развернуть на своем сервере. Объектное хранилище может служить для нее хранилищем файлов: тогда на диске ВМ остаются только приложение и база данных.

Есть два способа подключить S3:

- **основное хранилище** — все файлы пользователей хранятся в бакете;
- **внешнее хранилище** — бакет подключается как отдельная папка.

## Основное хранилище

> [!WARNING]
> Настройте основное хранилище **до первого запуска** Nextcloud. Файлы, уже загруженные на локальный диск, не переносятся в S3 автоматически.

Добавьте блок `objectstore` в `config/config.php`:

```php
'objectstore' => [
    'class' => '\\OC\\Files\\ObjectStore\\S3',
    'arguments' => [
        'bucket' => 'my-nextcloud',
        'hostname' => 's3.uzcstorage.uz',
        'port' => 443,
        'use_ssl' => true,
        'region' => 'default',
        'key' => '<Access Key>',
        'secret' => '<Secret Key>',
        'use_path_style' => true,
        'autocreate' => false,
    ],
],
```

Nextcloud хранит файлы в бакете как объекты с именами `urn:oid:<id>`, поэтому напрямую в бакете файлы не читаются. Делайте резервную копию и базы данных Nextcloud: без нее файлы невозможно сопоставить с пользователями.

## Внешнее хранилище

1. Включите приложение **External storage support** в разделе **Apps**.
2. Откройте **Administration settings → External storage**.
3. Добавьте хранилище типа **Amazon S3** и заполните: **Bucket** — имя бакета, **Hostname** — `s3.uzcstorage.uz`, **Port** — `443`, **Region** — `default`, отметьте **Enable SSL** и **Enable Path Style** и введите **Access key** и **Secret key**.
4. Выберите пользователей или группы, которым доступна папка. Зеленый индикатор рядом с хранилищем означает, что подключение работает.
