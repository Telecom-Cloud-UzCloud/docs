# Управление объектным хранилищем

## Управление объектным хранилищем

Чтобы открыть хранилище, нажмите на его имя на странице **Object Storage**. На странице **Object Storage Overview** показаны сведения о хранилище и его бакеты.

![Object Storage Overview](../../images/ob-8.png)

### Кнопки действий

На карточке хранилища показаны проект, расположение, размер, стоимость за все время, использование и дата создания. Кнопки действий расположены справа.

![Кнопки действий](../../images/ob-9.png)

- **Refresh** — обновляет статус и данные хранилища.
- **Sync Buckets** — синхронизирует список бакетов с хранилищем.
- **Credentials** — показывает адрес S3 и ключи доступа.
- **Upgrade/Downgrade Store** — изменяет размер хранилища.
- **Delete Object Storage** — безвозвратно удаляет хранилище.

### Просмотр учетных данных

- Нажмите **Credentials**. В окне **S3 Object Storage Credentials** показаны регион (**Region**), адрес S3 (**URL**, `https://s3.uzcstorage.uz`) и ваши ключи доступа (**Access Keys**).

![Учетные данные](../../images/ob-17.png)

- Правила для ключей доступа:
  - Можно иметь до 2 активных ключей. Создайте второй ключ для ротации; третий ключ будет недоступен, пока вы не отзовете один из имеющихся.
  - Всегда должен оставаться хотя бы 1 активный ключ. Удалить последний ключ нельзя.
  - После нажатия **Create Key** скопируйте секретный ключ в течение 5 минут. После этого секрет скрывается, а ключ остается активным.
  - Отзыв ключа прекращает его использование.
- Типичная ротация: создайте ключ №2 → переключите приложения на него → отзовите ключ №1.

### Изменение размера хранилища

- Нажмите **Upgrade/Downgrade Store**. В окне **Resize Object Storage** укажите новый размер в ГБ.
- Выберите **Billing Cycle**, проверьте сумму к оплате (**Payable Amount**) и нажмите **Resize**.

![Изменение размера](../../images/ob-18.png)

### Создание бакета

- В разделе **Buckets** нажмите **+ Create Bucket**.
- Укажите имя бакета в поле **Bucket Name**.
- При необходимости включите **Bucket Versioning**: тогда можно будет получить и восстановить любую предыдущую версию объекта в бакете.
- Включите **Object Locking**, чтобы хранить объекты по модели WORM (write-once-read-many, «однократная запись, многократное чтение»). Тогда объекты нельзя будет удалить или перезаписать в течение заданного срока или бессрочно.
- При желании задайте политику бакета в формате JSON в поле **Bucket Policy** (см. **Policy Examples** и **Policy Generator**) и права доступа в блоке **ACL**.
- Нажмите **Create**.

![Создание бакета](../../images/ob-11.png)

> [!NOTE]
> - Object Locking работает только в бакетах с включенным версионированием.
> - Object Lock — постоянная настройка: после включения для бакета ее нельзя отключить, а версионирование больше нельзя выключить.
> - Версии объектов учитываются в общей стоимости хранения данных.

### Публичный доступ к бакету

- В таблице бакетов показаны имя, URL бакета, количество файлов, общий объем, тип доступа (**Public** или **Private**) и дата создания.
- Чтобы изменить публичный доступ, нажмите на значок «Поделиться» в строке бакета (или **Share Bucket** на странице бакета), включите или выключите **Update Public Access** и нажмите **Update**.

![Изменение публичного доступа](../../images/ob-14.png)

> [!WARNING]
> При включенном публичном доступе любой, у кого есть ссылка на объект, может открыть его без каких-либо прав. Изменение публичного доступа может изменить настройки ACL бакета.

### Обзор бакета

- Нажмите на имя бакета, чтобы открыть страницу **Bucket Overview**. На ней показаны количество файлов, URL бакета, использование, дата создания и тип доступа.
- Кнопки действий позволяют обновить данные (**Refresh**), поделиться бакетом (**Share Bucket**), изменить его (**Update Bucket**) и удалить.

![Обзор бакета](../../images/ob-12.png)

- В файловом менеджере можно просматривать папки, загружать файлы (**Upload Files**) и создавать папки (**Create Folder**). Меню (три точки) рядом с файлом открывает действия с ним. Для каждого файла показаны дата создания, размер и статус публичного доступа.

![Файловый менеджер](../../images/ob-15.png)

### Заключение

Следуя этому руководству, вы сможете управлять объектным хранилищем: получать ключи доступа, менять размер хранилища, создавать бакеты и управлять доступом к ним. Если нужна помощь, изучите документацию UzCloud или обратитесь в поддержку.
