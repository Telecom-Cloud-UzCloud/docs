# Подключение по S3

Объектное хранилище UzCloud совместимо с Amazon S3 API: с ним можно работать из консоли и из любого S3-клиента или SDK. В этой статье собраны параметры, которые нужны любому клиенту.

## Параметры подключения

| Параметр | Значение |
|---|---|
| Адрес (endpoint) | `https://s3.uzcstorage.uz` |
| Регион | `default` |
| Стиль адресации | path-style: `https://s3.uzcstorage.uz/<бакет>/<объект>` |
| Access Key / Secret Key | ключи вашего объектного хранилища |

> [!IMPORTANT]
> Указывайте имя бакета точно так, как оно показано в консоли, например `demo-store-001045`.

## Ключи доступа

1. Откройте **Object Storage** в консоли и нажмите на имя хранилища.
2. Нажмите **Credentials**. Access Key показан в списке **Access Keys**.
3. Secret Key показывается только в течение 5 минут после нажатия **Create Key**. Скопируйте его сразу и сохраните в менеджере паролей. Если секрет утерян, создайте новый ключ и отзовите старый.

## Настройки клиента

Кроме адреса, региона и ключей, проверьте в своем инструменте или SDK две настройки:

- **Адресация path-style** должна быть включена. В разных клиентах параметр называется по-разному: `addressing_style = path`, `forcePathStyle`, `use_path_style_endpoint`, `UsePathStyle`, `force_path_style`.
- **Контрольные суммы** — `when_required`. Новые версии AWS CLI и AWS SDK по умолчанию добавляют заголовки контрольных сумм к каждому запросу; эта настройка оставляет их только там, где этого требует S3 API.

Готовые настройки для популярных клиентов:

- Командная строка: **[AWS CLI](tools/aws-cli.md)**, **[s3cmd](tools/s3cmd.md)**, **[rclone](tools/rclone.md)**, **[s3fs](tools/s3fs.md)**.
- Файловые менеджеры: **[Cyberduck](tools/cyberduck.md)**, **[S3 Browser](tools/s3-browser.md)**.
- Языки программирования: **[Python](sdk/python.md)**, **[JavaScript](sdk/javascript.md)**, **[PHP](sdk/php.md)**, **[Go](sdk/go.md)**.

> [!TIP]
> Подойдет и любая другая библиотека или программа, которая поддерживает собственный адрес S3: например, AWS SDK для Java и .NET, клиенты MinIO или программы резервного копирования с поддержкой S3.
