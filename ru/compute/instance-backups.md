# Резервные копии ВМ

## Резервное копирование виртуальных машин в UzCloud

**Резервные копии** сохраняют данные виртуальной машины и защищают их от случайного удаления, сбоев ПО и угроз безопасности.

- На странице **Virtual Machine Overview** откройте вкладку **Backups**. Здесь отображаются все резервные копии ВМ — созданные вручную и по расписанию.
- Нажмите **+ Create New**, чтобы создать резервную копию.
- Чтобы резервные копии создавались автоматически по расписанию, используйте вкладку **Schedules**.
