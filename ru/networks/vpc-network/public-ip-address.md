# Публичный IP-адрес

## Публичный IP-адрес

Публичные IP-адреса позволяют ресурсам VPC взаимодействовать с интернетом.

- На странице VPC откройте вкладку **Public IP Addresses**. На ней перечислены IP-адреса VPC: тип, ВМ и VPC. Адрес **SOURCE-NAT** назначается VPC автоматически и используется для исходящего трафика.

![Публичные IP-адреса](../../../images/vpc-net-5.png)

- Чтобы получить еще один адрес, нажмите **+ Acquire New IP**.
- Выберите **Billing Cycle**, проверьте **Price Summary** и нажмите **Buy IP**.

![Получение нового IP-адреса](../../../images/vpc-net-6.png)

- О настройке брандмауэра, проброса портов и VPN для адреса см. **[Публичный IP-адрес](../public-ip-address.md)**.

### Заключение

На вкладке **Public IP Addresses** можно просматривать, получать и настраивать IP-адреса VPC.
