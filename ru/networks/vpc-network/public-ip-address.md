# Публичный IP-адрес

## Публичный IP-адрес

- Публичные IP-адреса позволяют ресурсам VPC взаимодействовать с интернетом.
- На вкладке **Public IP Addresses** отображаются все назначенные публичные IP-адреса.

![Публичные IP-адреса](../../../images/vpc-net-5.png)

- Нажмите **Aquire New IP**, чтобы запросить новый публичный IP-адрес.
- Выберите нужный **Billing Cycle** и нажмите **Buy IP**.

![Покупка IP-адреса](../../../images/vpc-net-6.png)

### Заключение

**Публичные IP-адреса** в VPC обеспечивают связь облачных ресурсов с интернетом. На вкладке Public IP можно легко получать, просматривать и управлять IP-адресами с гибкими вариантами оплаты.
