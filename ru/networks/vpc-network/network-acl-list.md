# Список сетевых ACL

## Список сетевых ACL

**Сетевой ACL** (Access Control List) работает как межсетевой экран, управляющий входящим и исходящим трафиком подсетей внутри VPC.

- На вкладке Network ACL List отображаются все ACL, настроенные в VPC.
- Нажмите **Add New List**, чтобы создать новый ACL. Укажите **Name** и **Description** с кратким описанием правил.
- Нажмите **Submit**, чтобы создать ACL.

![Список сетевых ACL](../../../images/vpc-net-7.png)

### Заключение

**Список сетевых ACL** — централизованный способ управлять правилами входящего и исходящего трафика подсетей VPC. Создавая и упорядочивая ACL, вы повышаете безопасность и лучше контролируете сетевое взаимодействие.
