# Обзор сети

## Обзор VPC-сети

Virtual Private Cloud (VPC) — логически изолированная сеть в облачной среде. Она позволяет управлять сетевыми параметрами: IP-адресацией, подсетями, маршрутизацией и безопасностью.

- Чтобы посмотреть сеть, откройте **Networks** и перейдите в раздел **VPC Networks** — здесь отображаются VPC-сети и их размер.

![Список VPC-сетей](../../../images/vpc-net-1.png)

- На вкладке **Details** отображаются подробные сведения о VPC-сети.

![Сведения о VPC-сети](../../../images/vpc-net-2.png)

- **VPC ID** — идентификатор VPC.
- **Description** — краткое описание назначения VPC.
- **Restart Network** — можно ли перезапустить сеть (True/False).
- **Account Name** — аккаунт-владелец VPC.
- **Domain Name** — домен, к которому привязана VPC.
- **Redundant VPC** — включено ли резервирование (высокая доступность) (True/False).
- **Network Domain** — домен для внутренней связи внутри VPC.
- **CIDR (Classless Inter-Domain Routing)** — диапазон IP-адресов, доступных в VPC.

### Заключение

**Обзор VPC-сети** содержит основные сведения о виртуальном частном облаке: идентификатор, домен, диапазон IP-адресов и настройки резервирования. Эта информация помогает отслеживать, управлять и оптимизировать сеть для безопасной и эффективной работы.
