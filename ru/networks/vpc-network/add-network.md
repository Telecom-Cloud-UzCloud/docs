# Добавление сети

## Добавление сети в VPC

На вкладке **Network** перечислены сети (уровни), созданные внутри VPC. К этим сетям подключаются ВМ, и у каждой сети может быть свой ACL.

- На странице VPC откройте вкладку **Network** и нажмите **Add Networks**.

![Вкладка Network](../../../images/vpc-net-3.png)

- Заполните форму **Add VPC Network**:
  - **Name** — имя сети.
  - **Description** — описание назначения сети.
  - **Network ACL List** — ACL, который управляет входящим и исходящим трафиком сети (например, `default_allow` или `default_deny`).
  - **Gateway** — шлюз сети (например, `10.0.0.1`). Он должен входить в адресное пространство VPC.
  - **Netmask** — маска сети (например, `255.255.255.0`).
- Нажмите **Submit**.

![Форма Add VPC Network](../../../images/vpc-net-4.png)

### Заключение

Добавление сетей в VPC позволяет разделить ее на подсети со своими шлюзами и ACL, чтобы лучше управлять трафиком и упорядочить ресурсы.
