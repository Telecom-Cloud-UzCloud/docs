# Добавление сети

## Добавление сети в VPC

На вкладке Network отображаются все сети, созданные внутри VPC. При необходимости можно добавить новую сеть.

- Перейдите на вкладку **Network** и нажмите **Add Network**, чтобы создать новую сеть.

![Вкладка Network](../../../images/vpc-net-3.png)

- Заполните форму с параметрами сети.

![Форма добавления сети](../../../images/vpc-net-4.png)

- **Name** — имя сети.
- **Description** — описание назначения сети.
- **Network** — CIDR-блок подсети (например, 192.168.1.0/24).
- **ACL (Access Control List)** — существующий или новый список контроля доступа для управления входящим и исходящим трафиком.
- **Gateway** — шлюз сети для маршрутизации трафика.
- **Network Mask** — маска сети.
- Нажмите **Submit**, чтобы создать сеть.

### Заключение

Добавление сетей в **VPC** позволяет задавать собственные подсети, шлюзы и ACL для лучшего контроля и организации трафика. При правильной настройке можно построить безопасную и эффективную сетевую среду под задачи проекта.
