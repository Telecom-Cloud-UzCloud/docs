# VPN-шлюз

## VPN-шлюз

**VPN-шлюз** обеспечивает защищенную связь между VPC и внешними сетями, например локальным дата-центром или другим облаком.

- На странице VPC откройте вкладку **VPN Gateway**. На ней показан VPN-шлюз VPC для соединений «сеть — сеть».
- Если шлюза еще нет, нажмите **+ Create Site To Site VPN**.

![VPN-шлюз](../../../images/vpc-net-9.png)

### Заключение

**VPN-шлюз** — защищенный мост между VPC и внешними сетями. После его создания настройте соединения на вкладке **[VPN Connections](vpn-connections.md)**.
