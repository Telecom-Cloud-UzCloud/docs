# Обзор сети

## Обзор публичной сети

Чтобы открыть публичную сеть, нажмите на ее имя на вкладке **Public Network** страницы **Networks**. На странице сети показаны дата создания и расположение. Кнопки действий в правом верхнем углу позволяют изменить сеть, обновить данные и удалить сеть.

![Страница публичной сети](../../../images/pub-net-1.png)

### Сведения

На вкладке **Details** показаны основные параметры сети.

![Сведения о сети](../../../images/pub-net-2.png)

- **Name** — имя сети.
- **Type** — тип сети (**Isolated**).
- **Traffic Type** — тип трафика (**Guest** — трафик ВМ).
- **Restart Required** — нужно ли перезапустить сеть, чтобы применить изменения.
- **Redundant Router** — используется ли резервный виртуальный маршрутизатор.
- **Persistant** — остается ли сеть активной даже без запущенных ВМ.
- **Gateway**, **Netmask** и **CIDR** — шлюз, маска и диапазон адресов сети.
- **Account** — учетная запись, которой принадлежит сеть.

### Вкладки сети

- **[Egress rules](egress-rules.md)** — правила исходящего трафика.
- **[Public IP Addresses](public-ip-addresses.md)** — публичные IP-адреса сети.
- **[Associated VMs](associated-vms.md)** — ВМ, подключенные к сети.

### Заключение

Страница сети содержит основные сведения о ее конфигурации — тип, шлюз, маску и CIDR — и дает доступ к правилам исходящего трафика и IP-адресам.
