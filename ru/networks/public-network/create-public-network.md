# Создание публичной сети

## Создание публичной сети

**Публичная сеть** в UzCloud обеспечивает доступ к облачным ресурсам из интернета. Она позволяет виртуальным машинам, приложениям и другим облачным сервисам взаимодействовать с внешними системами через интернет. Публичные сети необходимы для размещения веб-приложений, API и других сервисов, которые должны быть доступны отовсюду.

- В меню слева откройте вкладку **Networks**.
- Откроется страница **Networks**. Перейдите на вкладку **Public Network**.

![Вкладка Public Network](../../../images/public-networks-1.png)

- Чтобы создать публичную сеть, нажмите значок **плюс (+)** в правой части страницы.

### Выбор расположения

- Выберите дата-центр, в котором будет физически размещена сеть.
- Выберите одно из доступных расположений.

![Выбор расположения](../../../images/public-networks-2.png)

### Привязка к проекту

- Привяжите сеть к одному из ваших проектов, чтобы удобно организовывать ресурсы и управлять ими.

![Привязка к проекту](../../../images/public-networks-3.png)

### Настройки сети

- Задайте шлюз и маску сети, чтобы определить маршрутизацию и структуру IP-адресов.

![Настройки сети](../../../images/public-networks-5.png)

### Имя публичной сети

- Укажите уникальное имя публичной сети, чтобы легко ее находить, и при желании добавьте описание ее назначения.

![Имя публичной сети](../../../images/public-networks-4.png)

### Создание публичной сети

- Выберите нужный **Billing Cycle**: почасовой или ежемесячный.
- Проверьте все параметры и итоговую стоимость. Нажмите **Create**, чтобы создать публичную сеть.

![Создание публичной сети](../../../images/public-networks-6.png)

### Заключение

Публичная сеть подключает облачные ресурсы к интернету и делает их доступными отовсюду. Настроив расположение, проект и параметры сети, вы получите надежную и управляемую сеть с гибкими вариантами оплаты.
