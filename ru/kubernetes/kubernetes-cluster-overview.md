# Обзор кластера Kubernetes

## Обзор кластера Kubernetes в UzCloud

Страница **Kubernetes Cluster Overview** содержит подробную сводку о кластере Kubernetes и инструменты управления им: конфигурацию кластера, характеристики ресурсов, метрики использования и быстрые действия.

---

### Кнопки действий

- Кнопки действий — быстрый доступ к основным операциям с Kubernetes.

![Кнопки действий](../../images/kb-m-0.png)

- Чтобы увидеть кнопки действий, нажмите на кластер — откроется страница **Kubernetes Cluster**.

![Подробные кнопки действий](../../images/kb-m-1.png)

- **Upgrade Kubernetes Version** — обновляет кластер до новой версии Kubernetes с улучшениями, исправлениями ошибок и патчами безопасности.
- **Refresh** — загружает актуальные данные кластера, включая статус и метрики ресурсов.
- **Download Config** — скачивает файл `kubeconfig` для работы с кластером через CLI-инструменты, например `kubectl`.
- **Power Off** — корректно выключает весь кластер Kubernetes.
- **Delete** — безвозвратно удаляет кластер и все связанные ресурсы.

### Обзор кластера

![Обзор кластера](../../images/kb-m-6.png)

- **Total CPU** — общее количество виртуальных процессоров (vCPU) на всех узлах кластера.
- **Total RAM** — общий объем памяти (в ГБ), выделенный кластеру.
- **Control Nodes** — узлы, которые управляют состоянием кластера и координируют рабочие узлы.
- **Worker Nodes** — узлы, на которых работают контейнерные нагрузки и приложения.
- **Network** — виртуальная сеть, в которой развернут кластер.
- **Status** — текущее состояние кластера (например, Running, Stopped).

### Информация о кластере

![Информация о кластере](../../images/kb-m-2.png)

- **Project Name** — имя проекта, в котором создан кластер.
- **Created At** — дата и время создания кластера.
- **IP Address** — публичный IP-адрес кластера.
- **End Point** — адрес API-сервера для доступа к кластеру.
- **Cloud** — облачный регион или провайдер, где размещен кластер.
- **Username** — имя пользователя по умолчанию для доступа к ресурсам кластера.
- **Location** — географическое расположение дата-центра.
- **Kubernetes Version** — текущая версия Kubernetes в кластере.
- **Auto Scaling** — если включено, кластер автоматически меняет количество узлов в зависимости от нагрузки.
- **Minimum Size / Maximum Size** — минимальное и максимальное количество узлов для автомасштабирования (если оно включено).
- **All Time Consumption** — общая стоимость работы кластера с момента создания.
- **Network** — имя сети, в которой работает кластер.
- **SSH Key** — SSH-ключ для безопасного доступа к узлам кластера.

### Конфигурация узлов

![Конфигурация узлов](../../images/kb-m-3.png)

- **Current Plan** — выбранный план инфраструктуры, определяющий ресурсы каждого узла (например, K8s Plan 1).
- **CPU** — количество vCPU на узел.
- **Memory** — объем RAM на узел.
- **Storage** — объем дискового хранилища на узел.
