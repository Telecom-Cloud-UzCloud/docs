# Создание кластера Kubernetes

## Кластер Kubernetes

Кластер **Kubernetes** — это набор преднастроенных машин (узлов), которые совместно запускают контейнерные приложения автоматически и масштабируемо. Kubernetes управляет развертыванием, масштабированием и работой контейнеров приложений на нескольких узлах.

В **UzCloud** можно легко создать кластер Kubernetes, чтобы управлять приложениями, масштабировать ресурсы и обеспечивать высокую доступность.

---

### Создание кластера Kubernetes

- В меню слева откройте вкладку **Kubernetes**.
- Откроется страница **Kubernetes**.

![Страница Kubernetes](../../images/kb-1.png)

- Чтобы создать кластер, нажмите **Create Cluster** или **Create New** в правой части страницы.

### Выбор расположения

- Выберите дата-центр, в котором будет развернут кластер Kubernetes.
- Выберите одно из доступных расположений.

![Выбор расположения](../../images/kb-7.png)

### Привязка к проекту

- Привяжите кластер к одному из ваших проектов, чтобы удобно организовывать ресурсы и управлять ими.

![Привязка к проекту](../../images/kb-2.png)

### Выбор сети

- Настройте или выберите сеть для кластера. Это может быть изолированная частная сеть; также можно создать эластичную сеть для связи нескольких регионов.
- Новую сеть можно создать, выбрав **Create New Network**.

![Выбор сети](../../images/kb-8.png)

### Мощность кластера

- Выберите готовый **Node Plan** с фиксированными параметрами CPU, памяти и хранилища.
- Для более точной настройки создайте **Custom Plan**, указав CPU, память, хранилище и количество узлов. Больше узлов — выше масштабируемость и равномернее распределение нагрузки.

![Мощность кластера](../../images/kb-3.png)

### Расширенные настройки (необязательно)

- Можно включить **Enable High Availability** для резервирования и добавить **Control Nodes** (управляющие узлы) для стабильной работы при сбоях.

![Расширенные настройки](../../images/kb-4.png)

- Настройте дополнительные параметры:

  - **Добавьте SSH-ключ** для безопасного доступа. Нажмите **Add Now**, чтобы добавить SSH-ключ.
  - **Примечание**: для некоторых образов ОС, например Arch Linux, SSH-ключ обязателен, так как вход по паролю не поддерживается.

![Добавление SSH-ключа](../../images/kb-9.png)

- Укажите имя SSH-ключа и его значение, затем нажмите **Add SSH Key**.

![Данные SSH-ключа](../../images/kb-10.png)

### Имя кластера

- Укажите уникальное **Cluster Name**, чтобы легко находить кластер в панели управления.

![Имя кластера](../../images/create-kubernetes-cluster-inline-e0a45aae.png)

### Создание кластера

- Выберите нужный **Billing Cycle**. Для Kubernetes поддерживаются периоды: почасовой, ежемесячный, ежеквартальный, раз в полгода, ежегодный, раз в два года и раз в три года.
- Поддерживаемые правила биллинга: Date to Date, Fixed Calendar Month, Unfixed Calendar Month, Fixed Prorata и Unfixed Prorata.
- Доступны разные пакеты кластеров в зависимости от потребностей в ресурсах (количество узлов, размер дисков) — это подходит для самых разных контейнерных нагрузок.
- Проверьте все параметры и итоговую стоимость. Нажмите **Create Cluster**, чтобы создать кластер.

![Создание кластера](../../images/kb-6.png)

### Заключение

Следуя этому руководству, вы легко создадите кластер Kubernetes в UzCloud и сможете управлять им. Кластеры Kubernetes — мощный инструмент для развертывания, масштабирования и управления контейнерными приложениями с высокой доступностью и эффективностью. Если нужна помощь, изучите документацию UzCloud или обратитесь в поддержку.
