# Импорт ISO

## ISO-образ

**ISO-образ** (по названию стандарта ISO — International Organization for Standardization) — это файл образа диска, содержащий точную копию файловой системы. В UzCloud ISO-образы используются для создания виртуальных машин, установки операционных систем и восстановления системы. В этом руководстве описано, как импортировать ISO-образ в UzCloud, управлять им и использовать его.

---

### Создание ISO-образа

- В меню слева откройте вкладку **ISOs**.
- Чтобы добавить ISO, нажмите **ISOs** или значок **плюс (+)** в правой части страницы. Откроется меню создания ISO.

![Страница ISO](../../images/iso-1.png)

### Выбор расположения

- Выберите дата-центр, в котором будет храниться ISO-образ.
- Выберите одно из доступных расположений.

![Выбор расположения](../../images/iso-2.png)

### Привязка к проекту

- Привяжите ISO-образ к одному из ваших проектов, чтобы удобно организовывать ресурсы и управлять ими.

![Привязка к проекту](../../images/iso-3.png)

### Параметры ISO

При создании ISO нужно заполнить несколько обязательных полей:

- **Operating System** — ОС для ISO-образа (например, Windows, Linux, macOS).
- **OS Version** — конкретная версия выбранной ОС (например, Windows 11, Ubuntu 22.04).
- **Image** — файл, из которого будет создан ISO.
- **URL** — корректная ссылка, если ISO-образ размещен в интернете.
- **Name** — имя ISO-файла для удобной идентификации.
- **Description** — краткое описание содержимого или назначения ISO.

Также можно выбрать дополнительные параметры:

- **Password Enabled** — для доступа к содержимому ISO потребуется пароль, что добавляет уровень защиты.
- **Is Bootable** — определяет, можно ли загружать систему с этого ISO. Если параметр включен, ISO можно записать на USB/DVD и использовать для установки или запуска ОС.
- **Is Extractable** — позволяет открывать и распаковывать ISO как обычный архив без специальных программ для монтирования.

![Параметры ISO](../../images/iso-4.png)

### Создание ISO

- Выберите нужный **Billing Cycle**. Для ISO поддерживается почасовая оплата.
- Поддерживаемые правила биллинга: Date to Date, Fixed Calendar Month, Unfixed Calendar Month, Fixed Prorata и Unfixed Prorata.
- Для ISO поддерживается только один пакет на зону — это простая модель учета использования загрузочных образов.
- Проверьте все параметры и итоговую стоимость. Нажмите **Review & Create ISO**, чтобы создать ISO для проекта.

![Создание ISO](../../images/iso-5.png)

### Заключение

Следуя этому руководству, вы легко создадите ISO-образы в UzCloud и сможете управлять ими. ISO-образы — универсальный способ развертывания операционных систем, создания виртуальных машин и восстановления системы. Если нужна помощь, изучите документацию UzCloud или обратитесь в поддержку.
