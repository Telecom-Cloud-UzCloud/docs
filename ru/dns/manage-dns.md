# Управление DNS

## Управление DNS в UzCloud

DNS-записи (Domain Name System) — важнейшие компоненты интернета, которые связывают доменные имена с конкретными сервисами: сайтами, почтой, механизмами безопасности. Каждый тип записи выполняет свою роль. Ниже подробно описан каждый тип записи и его поля.

---

После активации DNS используйте панель управления, чтобы просматривать серверы имен (name servers), создавать записи и управлять ими.

![Страница DNS](../../images/man-dns-1.png)

- Чтобы использовать DNS-сервис, укажите эти серверы имен у регистратора вашего домена.
- Используйте `@`, чтобы создать запись для корня домена, или укажите имя хоста, чтобы создать ее для поддомена. Записи A предназначены только для IPv4-адресов и указывают, куда должны направляться запросы к домену.
- Чтобы создать запись, нажмите **Create Record**.

![Создание записи](../../images/man-dns-2.png)

- Заполните поля, соответствующие выбранному типу записи.

![Параметры записи](../../images/man-dns-3.png)

### Запись A (Address Record)

Запись **A** связывает доменное имя с IPv4-адресом. Благодаря ей пользователи, вводящие домен, например `example.com`, попадают на IP-адрес нужного веб-сервера.

**Основное:**

- **Назначение:** связывает доменные имена с IPv4-адресами.
- **Enter `@` or hostname:** `@` — для корневого домена, имя хоста — для поддоменов.
- **Points To:** `192.0.2.1`
- **TTL (секунды):** `14400`

**Пример записи:**

```text
@    A    192.0.2.1    14400
```

### Запись AAAA (IPv6 Address Record)

Запись **AAAA** связывает доменные имена с IPv6-адресами.

**Основное:**

- **Назначение:** связывает доменные имена с IPv6-адресами.
- **Enter `@` or hostname:** `@` — для корневого домена, имя хоста — для поддоменов.
- **Points To:** `2001:0db8:85a3:0000:0000:8a2e:0370:7334`
- **TTL (секунды):** `14400`

**Пример записи:**

```text
@    AAAA    2001:0db8:85a3:0000:0000:8a2e:0370:7334    14400
```

### Запись CNAME (Canonical Name Record)

Запись **CNAME** создает псевдоним доменного имени и перенаправляет запросы с одного домена на другой.

**Основное:**

- **Назначение:** делает один домен псевдонимом другого.
- **Enter `@` or hostname:** `@` — для корневого домена, имя хоста — для поддоменов.
- **Target:** `example.com.`
- **TTL (секунды):** `14400`

**Пример записи:**

```text
blog    CNAME    example.com.    14400
```

### Запись MX (Mail Exchange Record)

Запись **MX** направляет почту домена на нужный почтовый сервер.

**Основное:**

- **Назначение:** направляет почту на указанный почтовый сервер.
- **Enter `@` or hostname:** `@` — для корневого домена, имя хоста — для поддоменов.
- **Priority:** `10`
- **Mail Server:** `mail.example.com.`
- **TTL (секунды):** `14400`

**Пример записи:**

```text
@    MX    10 mail.example.com.    14400
```

### Запись TXT (Text Record)

Запись **TXT** хранит произвольный текст и широко используется для подтверждения владения доменом, защиты почты и других целей.

**Основное:**

- **Назначение:** хранит текстовую информацию для проверки или безопасности.
- **Enter `@` or hostname:** `@` — для корневого домена, имя хоста — для поддоменов.
- **TXT Value:** `v=spf1 mx -all`
- **TTL (секунды):** `14400`

**Пример SPF-записи:**

```text
@    TXT    "v=spf1 mx -all"    14400
```

### Запись NS (Name Server Record)

Запись **NS** указывает авторитетные DNS-серверы домена.

**Основное:**

- **Назначение:** задает авторитетные серверы имен домена.
- **Enter `@` or hostname:** `@` — для корневого домена, имя хоста — для поддоменов.
- **Nameserver:** `ns1.example.com.`
- **TTL (секунды):** `14400`

**Пример записи:**

```text
@    NS    ns1.example.com.    14400
```

### Запись SRV (Service Record)

Запись **SRV** задает параметры для поиска определенных сервисов в домене.

**Основное:**

- **Назначение:** указывает серверы, на которых размещены определенные сервисы.
- **Enter `@` or hostname:** `@` — для корневого домена, имя хоста — для поддоменов.
- **Priority:** `10`
- **Weight:** `60`
- **Port:** `5060`
- **Target:** `sipserver.example.com.`
- **TTL (секунды):** `14400`

**Пример SIP-записи:**

```text
_sip._tcp    SRV    10 60 5060 sipserver.example.com.    14400
```

### Запись SOA (Start of Authority Record)

Запись **SOA** содержит основные административные сведения о DNS-зоне.

**Основное:**

- **Назначение:** предоставляет ключевую информацию для управления DNS-зоной.
- **TTL (секунды):** `86400`

**Пример записи:**

```text
@    SOA    ns1.example.com admin.example.com 2024031001 7200 3600 1209600 86400
```

### Заключение

Понимая типы DNS-записей и умея ими управлять, вы сможете эффективно настроить работу домена. Направляете ли вы трафик, защищаете почту или настраиваете сервисы, DNS-записи необходимы для надежного присутствия в интернете. Если нужна помощь, изучите документацию UzCloud или обратитесь в поддержку.
